CONTROLE DE ATIVIDADE FÍSICA DO EFETIVO — V12 FIREBASE

Esta versão foi migrada do Supabase para o Firebase/Cloud Firestore porque o domínio do Supabase estava sendo bloqueado na rede utilizada.

Principais ajustes:
- Firebase Authentication para login.
- Cloud Firestore para usuários e atividades.
- Configuração do projeto Firebase já inserida em config.js.
- RE 109139-5 mapeado para ferpozzer@gmail.com para permitir login pelo RE ou pelo e-mail.
- Documento de usuário esperado em usuarios/{UID}.
- Atividades gravadas em atividades com userUid do policial autenticado.
- Registro nasce como PENDENTE e é alterado para ASSINADO na confirmação definitiva.
- Assinatura usada em cada atividade é copiada para o próprio registro antes da assinatura definitiva.
- Registros ASSINADOS ficam bloqueados pelas Regras do Firestore já configuradas no projeto.
- Balé mantido na lista de atividades.
- Identificação no padrão Graduação + RE + Nome.
- Rodapé: CRIADO POR: SUBTEN PM 109139-5 POZZER.
- PWA e GitHub Pages preservados.
- Cache atualizado para caf-efetivo-v12-firebase.

IMPORTANTE SOBRE A ASSINATURA ATUAL:
A assinatura pessoal usada como modelo fica salva no navegador/dispositivo. A cópia da assinatura usada em cada registro é armazenada no próprio documento da atividade no Firestore, tornando o registro assinado independente de alterações futuras na assinatura.

CADASTRO DE NOVOS USUÁRIOS:
O Administrador pode usar a tela Efetivo. Usuários sem e-mail recebem login interno baseado no RE. Usuários com e-mail usam o e-mail como login. Para o usuário 109139-5 foi incluído o mapeamento de RE para o e-mail já criado no Firebase Authentication.
